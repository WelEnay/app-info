Политика обработки данных

WebOps получает данные выбранных Google Таблиц через Google API с разрешения пользователя. Значения ячеек, формулы, оформление и служебные сведения используются для чтения таблиц, подготовки и выполнения запрошенных изменений.

Рабочие данные и журналы операций могут сохраняться локально на устройстве пользователя. Сведения об авторизации хранятся в защищённом хранилище операционной системы.

При выполнении поручений необходимые данные могут обрабатываться Google и подключёнными сервисами, выбранными пользователем, в соответствии с настройками и условиями этих сервисов.

Пользователь может отозвать доступ приложения в настройках Google-аккаунта. Сохранённые локальные данные и сведения об авторизации удаляются отдельно на устройстве пользователя. Отзыв доступа не удаляет ранее сохранённые файлы.

По вопросам работы приложения можно обратиться по адресу поддержки, указанному на экране согласия Google.
