WebOps

WebOps — локальный инструмент для работы с корпоративными задачами и расписанием. Он помогает подготовить постановку задачи, проверить занятость и составить план для согласования.

Google-аккаунт используется для чтения расписания и записи согласованных изменений в Google Таблицы через официальный Google Sheets API. Для задач используется официальный API системы управления задачами.

Вход в Google выполняется владельцем аккаунта. Сохранённая авторизация позволяет обновлять токен при запуске инструмента. Каждая корпоративная запись требует отдельного согласования конкретного плана.

Инструмент предназначен для ограниченного круга пользователей. Эта страница описывает его назначение и не предоставляет доступ к задачам, таблицам или сохранённой авторизации.
