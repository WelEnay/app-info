WebOps

Приложение для работы с Google Таблицами. Позволяет просматривать данные, подготавливать и вносить изменения по запросу пользователя.

Доступ к Google-аккаунту предоставляется самим пользователем. Приложение использует его для выполнения запрошенных операций с таблицами.
